Local storage and access
This workbench saves matter records, aggregate metrics, policy drafts, public-source snapshots, settings, and activity in .data/atlas.sqlite3 on this computer. The database is excluded from Git and blocked from the web server’s static routes.
The server binds to 127.0.0.1 only. Mutating requests require a same-origin browser request header. These safeguards are not a substitute for authentication, encryption at rest, role permissions, or production tenant isolation. Anyone with local access to this app can switch between the demo societies.
Public source checks contact only approved LSC HTTPS hosts. No entered policy or metric data is sent to those sources. Monitoring stops when the server stops. Stop the server and back up or remove the database to reset local persistent data.
The separate applicant planner and court-outcome lab remain browser-memory-only unless you explicitly download files.
